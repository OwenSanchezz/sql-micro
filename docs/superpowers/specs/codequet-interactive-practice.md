# Prácticas interactivas de CodeQuet

## Objetivo

Hacer que cada lección enseñe mediante pequeñas acciones: leer código, predecir un resultado, ensamblar instrucciones y recibir retroalimentación clara antes de avanzar.

## Referencia aceptada

Las grabaciones muestran preguntas de opción múltiple con un ejemplo de código visible, un banco de piezas tocables para construir líneas, ordenamiento de instrucciones y proyectos guiados divididos en pasos. CodeQuet conservará su identidad visual, Quet, sus rutas y el avance de Inicio → Practicar.

## Diseño

- Las preguntas rápidas muestran el fragmento de código relacionado con la pregunta y explican el concepto después del intento.
- La práctica de SQL conserva el editor y la ejecución real de consultas en su base didáctica.
- En Python, Java, web, Linux, PostgreSQL guiado, Docker, redes/nube y portafolio, la solución aparece como piezas reordenadas; el estudiante las toca para construir el código o procedimiento desde cero.
- Cada pieza colocada se puede retirar; hay progreso visible, botón para deshacer/reiniciar y pistas de Quet en dos niveles.
- La respuesta completa y el análisis línea por línea aparecen solo después de completar el ejercicio. Los intentos incorrectos indican qué revisar sin perder vidas.
- Los proyectos guiados se conservan en la ruta de portafolio y sus retos usan el mismo constructor paso a paso, sin ofertas de pago.
- Los controles funcionan en pantalla táctil, teclado y lector de pantalla; las piezas se ajustan a teléfonos.

## Límites

- La aplicación no ejecutará comandos reales de Linux, PostgreSQL, Docker o nube. Esos ejercicios serán simulaciones de código y decisiones.
- SQL seguirá siendo ejecutable localmente mediante SQL.js.
- No se añadirá una ruta de pago, cuenta nueva ni servicio remoto.
